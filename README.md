## GitHub Pages-da ishga tushirish

1. Ushbu repozitoriyni GitHub hisobingizga yuklang (`main` branch).
2. Repozitoriy **Settings** -> **Pages** bo‘limiga kiring.
3. **Source** sifatida `Deploy from a branch` -> `main` -> `/(root)` ni tanlang va **Save** tugmasini bosing.
4. 1-2 daqiqada saytingiz `https://<sizning-username>.github.io/<repo-nomi>/` manzilida ishga tushadi.
